# Судоку (PWA)

Судоку с четырьмя уровнями сложности. Устанавливается на главный экран iPhone и Android, работает офлайн, без фреймворков и сборки.

## Возможности

- Генератор головоломок с единственным решением: Легкий, Средний, Сложный, Эксперт
- Подсветка конфликтов в реальном времени, кнопка «Проверить», до 3 ошибок на партию
- Заметки-кандидаты с автоудалением, отмена и повтор (до 100 шагов), 3 подсказки
- Таймер, пауза (автопауза при сворачивании), автосохранение и «Продолжить игру»
- Статистика: лучшее время по уровням, история партий, достижения
- Светлая и тёмная темы (системная по умолчанию, ручное переключение)
- Звуки (WebAudio, без файлов) и вибрация (только Android), оба отключаются в меню
- Safe area (вырез, Dynamic Island, punch-hole), портретная и ландшафтная раскладки

## Запуск для проверки

Service worker и установка работают только по HTTPS или на `localhost`:

```bash
cd sudoku-pwa
python3 -m http.server 8080
# открыть http://localhost:8080
```

Для проверки на телефоне выложите папку на любой HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages). Пути относительные, поэтому работает и в корне домена, и в подпапке.

## Установка

**iPhone (Safari):** «Поделиться» → «На экран Домой». Только Safari: другие браузеры на iOS не умеют ставить PWA в полноэкранном режиме.

**Android (Chrome):** кнопка «Установить приложение» в меню игры или пункт «Установить приложение» в меню браузера.

## Проверка офлайн

1. Откройте приложение онлайн и дождитесь полной загрузки.
2. Включите авиарежим и перезапустите приложение.
3. Меню и игра должны работать без сети.

## Структура

```
index.html        разметка: меню, статистика, игра, диалог
manifest.json     манифест PWA
sw.js             service worker (офлайн-кеш)
css/main.css      сброс, safe area, меню, статистика, кнопки
css/game.css      поле, клетки, диалоги, анимации, ландшафт
css/themes.css    цвета светлой и тёмной тем
js/sudoku.js      решатель, генератор, валидатор, класс Game (без DOM)
js/storage.js     localStorage: партия, история, статистика, настройки
js/audio.js       звук и вибрация (слушает событие sudoku:event)
js/ui.js          отрисовка, события, таймер, диалоги, статистика
js/app.js         старт, экраны, тема, установка, регистрация SW
icons/            180 (iOS), 192/512 (Android), maskable-512
```

## Выпуск обновления

При любом изменении файлов увеличьте `CACHE_VERSION` в `sw.js`, иначе пользователи останутся на старой версии из кеша. Новая версия подхватывается при следующем запуске. Если добавляете новый файл, добавьте его в `STATIC_ASSETS`.

## Ограничения платформ

- **iOS:** вибрации в PWA нет, переключатель в меню скрыт автоматически. Звук WebAudio отключается аппаратным переключателем «Без звука» на боковой стороне iPhone.
- **iOS:** полноэкранный режим только при запуске с иконки на главном экране, не из вкладки Safari.
- **Данные** хранятся в localStorage устройства; если очистить данные сайта, прогресс и статистика пропадут.
